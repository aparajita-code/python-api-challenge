# WeatherPy and VacationPy Analysis
This repository contains Python-based projects (WeatherPy and VacationPy) to analyze weather patterns and create interactive travel destination maps using APIs and visualization tools.

***Part 1: WeatherPy***
Analyzes the relationship between various weather variables and latitude using:

Weather Data Retrieval: Utilizes the OpenWeatherMap API.

Scatter Plots: Latitude vs. temperature, humidity, cloudiness, and wind speed.

Linear Regression: Generates regression models for weather metrics in the Northern and Southern Hemispheres.

***Part 2: VacationPy***
Creates an interactive travel destination map by:

City Mapping: Displays all cities from a weather dataset.

Ideal Weather Filtering: Filters cities based on selected weather conditions.

Hotel Search: Uses the Geoapify API to find nearby hotels and includes their names and countries in the map hover messages.

***Features***
Dynamic data retrieval and manipulation with Python.

Advanced visualization using Matplotlib and interactive mapping tools.

Integration with APIs for weather and geographical data.

***How to Use***
Clone the repository.

Install necessary Python libraries (e.g., pandas, matplotlib, requests, geopy, etc.).

Add your API keys for OpenWeatherMap and Geoapify to the scripts.

Run the scripts:

WeatherPy: Analyze weather and create scatter plots.

VacationPy: Filter cities and map travel destinations.
